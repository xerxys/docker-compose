# Xerxys Mediaserver Stack
### Overview
- This is my personal configuration for an *arr stack with miscellaneous services (for example immich for my wedding photos)
- I have encrypted my .env files with git-crypt since they contain sensitive information like secret keys and identifying information
- Easy to recreate by combing through each yaml file and simply adding each variable into your own .env file (placed in the same folder as its corresponding yaml file) and assigning them to YOUR OWN values
